🚀 Enviament Massiu d'Informes Personalitzats (Google Workspace)

Aquest projecte permet automatitzar l'enviament de correus electrònics a una llista d'alumnes, adjuntant a cadascun el seu fitxer corresponent (PDF, Doc, etc.) cercat automàticament en una estructura de carpetes a Google Drive.

És una solució ideal per a centres educatius que necessiten enviar butlletins de notes o informes de qualificacions de forma massiva i segura.

📋 Característiques

  • Cerca automàtica per RAL/Referència: L'script busca el fitxer que contingui el codi de l'alumne en qualsevol subcarpeta.
  • Multireceptor: Permet enviar el mateix correu a dues adreces simultàniament (ex. pare i mare).
  • Personalització dinàmica: Substitució automàtica del nom de l'alumne en l'assumpte i el cos del missatge.
  • Gestió d'estat: Marca les files com a "Enviat" per evitar duplicats i permetre reprendre el procés si s'atura.
  • Panell de control: Configuració total des del mateix full de càlcul (sense tocar el codi).

🛠️ Requisits i Estructura

1. Google Drive

  • Una Carpeta Arrel que contingui els fitxers (poden estar organitzats en subcarpetes per curs, l'script les explorarà totes).
  • Els fitxers han de tenir en el seu nom el codi de referència (RAL) que apareix al full de càlcul.

2. Full de Càlcul (Google Sheets)

El fitxer de Google Sheets ha de tenir dues pestanyes obligatòries:

Pestanya 1: Dades (o qualsevol nom, però ha de ser la primera)
NomCognomsRAL / RefCorreu 1Correu 2Estat
..................
Pestanya 2: Configuracio (nom exacte)
ID Carpeta Arrel[L'ID de la teva carpeta de Drive]
Assumpte BaseInforme de qualificacions -
Nom RemitentSecretaria de l'Escola
Cos del MissatgeBon dia, \n\n Us adjuntem l'informe de {nom}...
Truc per a salts de línia: Per fer salts de línia al cos del missatge dins la cel·la de Google Sheets, prem Alt + Intro.

💻 El Codi (Google Apps Script)

Per instal·lar-lo, ves al teu full de càlcul, entra a Extensions > Apps Script, esborra-ho tot i enganxa el codi següent:

/**
 * CREACIÓ DEL MENÚ AMB DUES OPCIONS D'AJUDA
 */
function onOpen() {
    const ui = SpreadsheetApp.getUi();
    ui.createMenu('🚀 Enviament Massiu')
        .addItem('❓ Com funciona?', 'mostrarFuncionament')
        .addItem('⚙️ Guia de Configuració', 'mostrarInstruccions')
        .addSeparator()
        .addItem('📧 ENVIAR CORREUS', 'confirmarEnviament')
        .addToUi();
}

/**
 * MISSATGE EXPLICATIU DEL FUNCIONAMENT (CONCEPTUAL)
 */
function mostrarFuncionament() {
    const ui = SpreadsheetApp.getUi();
    const títol = "Com funciona aquest sistema?";
    const missatge =
        "Aquest script automatitza l'enviament d'informes personalitzats:\n\n" +
        "1. L'script entra a la carpeta principal que hagis indicat.\n" +
        "2. Reconeix totes les subcarpetes (cursos) i en fa un inventari intern.\n" +
        "3. Per a cada alumne del full, busca un fitxer que contingui el seu RAL (Columna C).\n" +
        "4. Si el troba, envia un correu personalitzat als correus de les columnes D i E.\n" +
        "5. Finalment, marca la fila com a 'Enviat' per no repetir el procés si el tornes a llançar.";
    ui.alert(títol, missatge, ui.ButtonSet.OK);
}

/**
 * GUIA DE CONFIGURACIÓ (TÈCNICA)
 */
function mostrarInstruccions() {
    const ui = SpreadsheetApp.getUi();
    const títol = "Guia de Configuració Tècnica";
    const missatge =
        "REQUISITS DELS FULLS:\n\n" +
        "1. PESTANYA 'Configuracio':\n" +
        " - B1: ID de la carpeta de Drive.\n" +
        " - B2: Assumpte (ex: Informe de...).\n" +
        " - B3: Nom que vols que aparegui com a remitent.\n" +
        " - B4: Text del missatge. Usa {nom} per posar el nom de l'alumne i \\n per fer salts de línia.\n\n" +
        "2. PESTANYA DE DADES (La primera de totes):\n" +
        " - A: Nom | B: Cognoms | C: RAL | D: Correu 1 | E: Correu 2 | F: Estat.\n\n" +
        "3. ELS FITXERS:\n" +
        " - El número RAL de la columna C ha de formar part del nom del fitxer de Drive.";
    ui.alert(títol, missatge, ui.ButtonSet.OK);
}

/**
 * CONFIRMACIÓ I ENVIAMENT
 */
function confirmarEnviament() {
    const ui = SpreadsheetApp.getUi();
    const resposta = ui.alert('Confirmació d\'enviament', 'Estàs a punt d\'enviar els correus segons la configuració del full. Vols continuar?', ui.ButtonSet.YES_NO);
    if (resposta == ui.Button.YES) enviarInformesMassius();
}

function enviarInformesMassius() {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const fullDades = ss.getSheets()[0];
    const fullConfig = ss.getSheetByName("Configuracio");
    if (!fullConfig) {
        SpreadsheetApp.getUi().alert("Error: No s'ha trobat el full 'Configuracio'");
        return;
    }

    // LECTURA DE LA CONFIGURACIÓ DEL FULL
    const valorsConfig = fullConfig.getRange("B1:B4").getValues();
    const idCarpeta = valorsConfig[0][0];
    const assumpteBase = valorsConfig[1][0];
    const nomRemitent = valorsConfig[2][0];
    const cosBase = valorsConfig[3][0];
    const dades = fullDades.getDataRange().getValues();
    const carpetaArrel = DriveApp.getFolderById(idCarpeta);

    console.log("Creant inventari de fitxers...");
    let diccionariFitxers = {};
    indexarCarpetaRecursivament(carpetaArrel, diccionariFitxers);
    let comptador = 0;

    for (let i = 1; i < dades.length; i++) {
        let nomComplet = dades[i][0] + " " + dades[i][1];
        let referencia = dades[i][2].toString().trim();
        let correu1 = dades[i][3];
        let correu2 = dades[i][4];
        let estat = dades[i][5];

        // Condicions per saltar la fila
        if (estat === "Enviat" || !referencia || !dades[i][0]) continue;

        let fitxerTrobat = null;
        for (let nomFitxer in diccionariFitxers) {
            if (nomFitxer.includes(referencia)) {
                fitxerTrobat = diccionariFitxers[nomFitxer];
                break;
            }
        }

        if (fitxerTrobat) {
            try {
                let llistaCorreus = [correu1, correu2].filter(c => c !== "" && c !== null);
                if (llistaCorreus.length > 0) {
                    let assumpte = assumpteBase + nomComplet;
                    let cos = cosBase.replace("{nom}", nomComplet).replace(/\\n/g, "\n");
                    GmailApp.sendEmail(llistaCorreus.join(","), assumpte, cos, {
                        attachments: [fitxerTrobat.getBlob()],
                        name: nomRemitent
                    });
                    fullDades.getRange(i + 1, 6).setValue("Enviat");
                    comptador++;
                }
            } catch (e) {
                fullDades.getRange(i + 1, 6).setValue("Error: " + e.toString());
            }
        } else {
            fullDades.getRange(i + 1, 6).setValue("Error: Fitxer no trobat");
        }
    }
    SpreadsheetApp.getUi().alert('Procés acabat', 'S\'han enviat ' + comptador + ' correus correctament.', SpreadsheetApp.getUi().ButtonSet.OK);
}

/**
 * FUNCIÓ RECURSIVA PER EXPLORAR CARPETES
 */
function indexarCarpetaRecursivament(carpeta, diccionari) {
    let fitxers = carpeta.getFiles();
    while (fitxers.hasNext()) {
        let f = fitxers.next();
        diccionari[f.getName()] = f;
    }
    let subcarpetes = carpeta.getFolders();
    while (subcarpetes.hasNext()) {
        indexarCarpetaRecursivament(subcarpetes.next(), diccionari);
    }
}

🚀 Instruccions de Posada en Marxa

  1. Copia el codi: Segueix els passos de la secció anterior.
  2. Autoritza l'script: En executar-lo per primer cop, Google et demanarà permisos. Clica a Configuració avançada > Ves a [Nom] (no segur).
  3. Prepara les dades: Omple el full de Dades amb la llista d'alumnes i el full de Configuracio amb l'ID de la carpeta.
  4. Test: Posa el teu correu personal en les dues primeres files per comprovar que el format és correcte.
  5. Enviament massiu: Clica el menú 🚀 Enviament Massiu > 📧 ENVIAR CORREUS.

⚠️ Consideracions Importants

  • Límits de Google: Els comptes de Workspace for Education tenen un límit de 1.500 correus/dia.
  • Temps d'execució: Google talla els scripts que duren més de 6-30 minuts. Si tens 800 correus i l'script s'atura, només cal tornar-lo a executar; continuarà per la fila on s'havia quedat gràcies a la marca d'estat "Enviat".
